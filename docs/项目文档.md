# 一、项目定位

奕安聚合科技（YIAN Tech Global）面向海外铁路客户的**国际销售与项目协调**官网。
以攀钢（Pangang）的制造能力作可信度背书，目标是把海外铁路买家转化为有效询价（RFQ）。

三条不可动摇的原则：

1. **网站主体是 YIAN Tech Global**，不是攀钢官网。
2. 攀钢只作为「制造来源」出现，措辞限定为
   *International sales and project coordination for railway rails manufactured by Pangang.*
3. **绝不编造** 技术参数、钢种、认证、产能、出口市场、客户名、交期、起订量。
   拿不到的数据一律留 `null` 并在页面隐藏。

# 三、视觉系统

## 3.1 调研依据

抓了 SSAB 与 voestalpine 两家国际钢轨/钢铁企业的官网实际页面：

| 公司 | 字体做法 |
| --- | --- |
| SSAB | 自制 **SSAB Sans Pro**（Light / Regular / Medium / Bold / Black 全套 + 斜体） |
| voestalpine | 自制 **voestalpine** 字体族（Ultralight / Light / Regular / Medium） |

**共同点：只管一种中性无衬线体，不外挂 Google 字体，不用等宽字体。**

## 3.2 字体

**全站单一 Archivo**（Google Fonts），零等宽、零第二字体。
（此前用过 IBM Plex + 大量等宽小标签，是"模板感 / AI 味"的主要来源，已全部清除。）

## 3.3 配色

| 角色 | 色板 | 说明 |
| --- | --- | --- |
| 结构色 | `ink`（近黑石墨 `#14181b` → `#0b0e10`） | 不用企业海军蓝 |
| 中性色 | `steel`（暖中性灰 `#f7f7f5` → `#2c2c28`） | 页面读起来像材料，不像 SaaS |
| 强调色 | `accent`（深红 `#b21e28`） | **只出现在主按钮、激活导航、必填星号** |

强调色的选择说明：曾用过企业蓝 + 橙（被判"低级"）、近黑 + 焦琥珀（被判"屎黄"）。
最终用**深红** —— 与热钢、道口信号的工业联想一致，且在暖调钢轨照片旁仍然立得住。
**除主按钮外不填任何大面积色块。**

## 3.4 版式规则

- 全站 **0 圆角**，结构靠 1px 细线。
- **不用阴影、不用悬浮位移**；hover 只改边框或文字色。
- 章节带编号（01 / 02 / 03…），编号用灰色，不用强调色。

## 3.5 骨架（关键）

**拒绝「标题 + 卡片网格」重复十遍的模板结构。** 首页段落类型刻意交替，且**产品降到"提一句"**：

### 交互模式

- **悬停展开 / 轻触展开（`.reveal` / `.reveal-group`）**：补充文案从标题或行下方滑出。
  - **桌面（支持悬停）**：鼠标移上去滑出，提示语与 +/− 图标在此显示。
  - **触屏与窄屏**：`BaseLayout` 里的脚本给 `<html>` 加 `.reveal-tap`，改为**轻触展开**，
    并补上 `role="button"` / `tabindex="0"` / `aria-expanded`，键盘回车与空格也能展开。
  - **无 JavaScript 时面板保持展开**，内容不会被藏起来。
- **轮播（`.carousel-track`）**：用原生 `scroll-snap` 实现，触屏滑动与键盘滚动都不依赖 JS；
  箭头和圆点只是驱动 `scrollTo`。

### 组件

`Hero`（轮播）· `StatBand`（数字条）· `OverlayBand`（全幅图带）· `PhotoEvidence`（实拍证据格）·
`RevealList`（悬停展开行）· `RailCatalogue`（规格行表，列表页复用，支持 `dataAttrs` 供筛选）

产品列表页同样是**规格行表**（左侧筛选栏 + 右侧行式目录），不是卡片网格。

# 六、内容与法律边界（长期遵守）

## 6.1 攀钢措辞

**不得**出现 `Official Pangang Website` / `Exclusive Distributor` / `Official Partner` /
`Authorized Agent` / `Sole Representative` 等表述 —— 除非项目方出具书面授权与确切措辞。
代码里已把 Pangang 限定在 *manufactured by Pangang* 这一类允许措辞内。
产品页的结构化数据**有意未标注 manufacturer**。

## 6.2 项目业绩的边界（重要）

`/projects` 页展示的是**攀钢制造的钢轨的应用业绩，不是 YIAN 承接的项目**。
页面上必须始终带着这句免责说明（i18n 键 `projectsPage.attribution`，**请勿删除**）：

> Rail referenced on this page was manufactured by Pangang. YIAN Tech Global coordinates
> international sales and project communication; the projects listed are not YIAN projects.
> Figures are drawn from public reporting.

## 6.3 不得编造

技术参数、钢种、认证、产能、出口市场、客户名、交期、MOQ、厂区归属 —— 一律不得推测填写。
生产页面不得出现 `Lorem ipsum` / `Unknown` / 假技术值。

## 6.4 浏览器自动翻译

中文浏览器打开站点时，Chrome 会把 **AREMA 翻成"阿拉伯环境管理协会"**、
**U75V 翻成"伊利诺伊大学芝加哥分校"**。已给技术标记加 `translate="no"`
（产品型号、标准名、规格表值、关键规格条、产品卡型号 / 标签 / 单重、页脚标准格子）。
**界面文案不要加**，那些翻译了反而更好。
